# Changelog

## 0.1.0 — 2026-11-27

- Initial release of HA Dashboard Fit.
- URL options for dashboard zoom, vertical body offset and horizontal view offset.
- Sections, Masonry and Panel content scaling instead of whole-page scaling,
  leaving HA dialogs outside the target.
- URL re-reading, inline-style restoration and delayed shadow-DOM discovery.
- Fixed-layer events plus discovery through `data-ha-scale-fixed`.
- Single-file distribution, custom-repository HACS metadata, EN/DE documentation,
  automated tests and CI/release workflows.

This first release remains experimental until validated on a real tablet.
